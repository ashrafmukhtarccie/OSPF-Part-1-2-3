

# OSPF Part 1, 2 & 3

## Overview

These labs cover the configuration and verification of OSPF dynamic routing.

## Objectives

* Configure OSPF
* Establish neighbor relationships
* Advertise networks
* Understand OSPF areas
* Verify routing tables

## Tools

* Cisco Packet Tracer
* Cisco IOS

## Outcome

Configured OSPF and verified dynamic route exchange between routers.
